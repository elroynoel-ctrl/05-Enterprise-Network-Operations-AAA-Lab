# CCNA v2.0 Objective Mapping

This practical review aligns with the direction of the announced CCNA v2.0 refresh. It is not an official Cisco course or exam activity.

| Lab activity | Skill demonstrated |
|---|---|
| VLANs and trunks | Layer 2 segmentation and 802.1Q |
| Router subinterfaces | Inter-VLAN routing |
| Static routes | IPv4 reachability and route selection |
| DHCP relay | Centralized address-service forwarding |
| DNS, NTP, Syslog, SNMP | Infrastructure operations |
| SSH | Secure device administration |
| RADIUS and TACACS+ | Centralized AAA concepts |
| Failure tests | Method-list behavior and troubleshooting |
| Break-glass access | Resilient management design |
| EXEC authorization/accounting | Administrative control and audit concepts |
| Simulation evidence | Packet-flow observation |
| Sanitization | Security-conscious documentation |
