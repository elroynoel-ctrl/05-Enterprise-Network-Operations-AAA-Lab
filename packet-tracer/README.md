# Packet Tracer Files

The original `.pkt` labs are intentionally not included in version control because their device and Server-PT configurations may expose inspectable credentials.

Before adding Packet Tracer files to a public repository:

1. Duplicate each original lab.
2. Replace all local passwords, enable secrets, AAA users, shared keys, and SNMP community strings with demonstration-only values.
3. Re-run the authentication, fallback, privilege, and reachability tests.
4. Inspect all device configurations and Server-PT service tables.
5. Add only the reviewed public-safe copies here.

The original working labs remain stored privately in Google Drive.
